# GA 8D Report

A shared 8D (Eight Disciplines) problem-solving report system for a quality team: a register of reports, a D0–D8 roadmap per report, actions with permanent IDs, automatic quality checks, an edit history, and PDF / Excel export.

`8d-report.html` is a single-file page written for Claude Artifacts. Team data, user names and file download come from the artifact runtime (`db`, `user` and `downloads` capabilities), so opened as a plain file it shows only the empty state. To run it as a team tool, publish it as an artifact with those three capabilities declared.
